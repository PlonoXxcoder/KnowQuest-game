Pour signaler une question après une réponse : ouvrir le formulaire avec le drapeau, choisir un motif et ajouter éventuellement un commentaire. Ne pas inclure de mot de passe ni d'information personnelle. Le commentaire est transmis à l'équipe via Oracle et le salon Discord prévu pour la modération. Un signalement ne modifie pas automatiquement la question et n'attribue pas de récompense.

Le client publié ne contient aucun secret Discord. Les scripts d'administration, rapports de travail, sauvegardes locales et fichiers d'environnement restent hors du dépôt public.
